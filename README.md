# FastReader
Browser-based RSVP speed-reading app built with React + Vite.

## Features
- Word-by-word RSVP display
- 100–1000 WPM control
- Play/pause and step controls
- Progress and stats
- Paste text or upload .txt
- Keyboard shortcuts
- Dark/light mode
- Client-side text processing

## Local development
npm install
npm run dev

## Deployment
GitHub Actions deploys the build to GitHub Pages from main.
